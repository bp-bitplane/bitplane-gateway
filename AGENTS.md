# bitplane-gateway

Host registry and router (`bpg-server`, `bpg`): reaches hosts over ssh, bootstraps `bp` and `bitplane-sessiond` on them, and forwards the sessiond protocol by host id.

## Agent skills

### Issue tracker

GitHub issues across the `bp-bitplane` repos, collected on org Project #1; cross-cutting work goes in `bitplane-protocol`. See `docs/agents/issue-tracker.md`.
